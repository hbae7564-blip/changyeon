# 사이트 콘텐츠 업데이트

`changyeon4277.github.io`는 링크인바이오 형태의 1인 사업 프로필 페이지다. `main` 브랜치에 push하면 1~2분 내 GitHub Pages에 그대로 반영되므로, 모든 변경은 곧 실사용자에게 노출된다는 전제로 작업한다.

## 사진 추가 워크플로우

1. 사용자가 새 사진 파일을 저장소 루트에 넣는다 (드래그 앤 드롭 또는 파일 복사)
2. `사진올리기.bat`를 실행하면 내부적으로 `node update-site.js`가 실행된다
3. `update-site.js`가 하는 일 (그대로 신뢰하고, 수동으로 대체 구현하지 말 것):
   - 저장소 루트의 `.jpg/.jpeg/.png` 파일 중 `index.html`에 아직 `src="..."`로 등장하지 않는 파일을 찾는다
   - 새 파일마다 `news-card` HTML 블록(사진 + "상담사례" 태그 + 고정 문구)을 생성
   - `<div class="news-scroll">` 마커를 찾아 그 안에 카드를 삽입
   - `git add -A && git commit && git push`까지 자동 실행
4. Claude가 대신 실행할 때도 반드시 `node update-site.js`를 호출한다 — 카드 HTML을 직접 손으로 작성해 삽입하지 않는다 (마커 위치·문구 포맷이 스크립트와 어긋나면 다음 실행이 깨진다)
5. 새로 추가할 사진이 없으면 스크립트가 "새로 추가할 사진이 없습니다"라고 안내하고 종료한다 — 정상 동작이다

## 소식 카드 문구를 사진마다 다르게 하고 싶을 때

기본 스크립트는 모든 새 사진에 동일한 고정 문구("고객님과 나눈 사주 상담 내용 일부를...")를 붙인다. 사용자가 사진별로 다른 설명을 요청하면:
1. 먼저 `node update-site.js`로 기본 카드를 생성·커밋한다
2. 이후 `index.html`에서 해당 카드의 `<h3>`/`<p>` 텍스트만 직접 수정한다 (마커 구조는 건드리지 않는다)
3. 변경 후 `git add -A && git commit -m "..." && git push`로 별도 커밋한다

## 프로필/링크 섹션 수정

- 프로필 소개 문구, 카카오톡/네이버 예약/구글 리뷰 링크 URL은 `index.html` 상단 `.profile`, 링크 버튼 영역에서 직접 찾아 수정한다
- 색상 테마는 `:root` 안의 CSS 변수(`--gold`, `--bg-deep` 등)로 관리되므로, 색을 바꿀 땐 개별 요소가 아니라 변수 값을 바꾼다

## 작업 후 확인

- `git push` 이후 1~2분 뒤 https://changyeon4277.github.io 에서 실제 반영을 사용자에게 확인해보라고 안내한다
- push 실패(인증 등)는 곧바로 화면 메시지를 사용자에게 그대로 보여달라고 요청한다 — 비개발자 사용자가 에러를 요약하면 원인 파악이 어려워지는 경우가 많다

## 후속 요청 처리

"저번에 올린 사진 문구 바꿔줘", "소식 순서 바꿔줘" 같은 후속 요청은 `git log --oneline -10`으로 최근 변경 이력을 먼저 확인한 뒤, 어떤 커밋/카드를 가리키는지 사용자와 확인하고 진행한다.
